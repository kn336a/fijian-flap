# Fijian Flap

A Flappy-Bird-style 8-bit browser game (beta). Open the page, tap or press any key to flap.

- Works on phones and desktop browsers, no install.
- Scores and progress are saved in your own browser (this beta has no shared leaderboard yet).
- Report bugs to the person who sent you the link.

Plain HTML + JavaScript. Entry point: `index.html`.
